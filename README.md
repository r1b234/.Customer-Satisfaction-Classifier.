# Customer Satisfaction Classifier CRM (Indian Customer Dataset)

Modular project structure with Streamlit, SQLite, Pandas, and custom NLP classification for Indian consumer survey comments.

## Files
- `app.py`: Streamlit Dashboard UI
- `main.py`: Entry point script
- `classifier.py`: NLP classification engine
- `crm_database.py`: SQLite handler
- `survey_data.csv`: CSV dataset with Indian customer reviews
- `test.py`: Unit test suite
